# Real Return Engine MCP Setup

The Real Return Engine MCP server is hosted at `https://www.realreturnengine.com/mcp` (Streamable HTTP transport) and requires no API key for its 4 core cross-asset forecast and backtest tools (`get_cross_asset_7y_forecast`, `get_100yr_backtest_summary`, `explain_methodology`, and `request_missing_asset_or_feature`).
